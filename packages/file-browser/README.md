# @groupsum/file-browser

File explorer React component package for Groupsum applications.

## Install

```bash
pnpm add @groupsum/file-browser
```

## Use

```tsx
import { FileBrowser } from '@groupsum/file-browser';
import '@groupsum/file-browser/style.css';
```

## Scripts

- `pnpm run typecheck`
- `pnpm run build`
