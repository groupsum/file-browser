# @groupsum/react-file-explorer-component

React file explorer component package for Groupsum applications.

## Install

```bash
pnpm add @groupsum/react-file-explorer-component
```

## Use

```tsx
import { FileExplorer } from '@groupsum/react-file-explorer-component';
import '@groupsum/react-file-explorer-component/style.css';
```

## Scripts

- `pnpm run typecheck`
- `pnpm run build`
